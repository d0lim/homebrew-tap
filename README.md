# homebrew-tap

Homebrew tap for d0lim's tools.

## Display Remember

[Display Remember](https://github.com/d0lim/display-remember) remembers physical
monitors and restores their saved layouts after reconnection or wake. Configure
displays in macOS System Settings, then save the layout in the app.

```sh
brew install --cask d0lim/tap/display-remember
```

Requires Apple Silicon and macOS 13 or later. The cask installs the app and the
`display-remember` CLI. Automatic restoration is opt-in while the app is running.
The app bundles displayplacer; no separate displayplacer installation is needed.
The Dock icon is hidden by default; show it from the app's Settings when needed.

`Casks/display-remember.rb` is generated by `scripts/update-cask.sh` in the
display-remember repository. Release archives are hosted in that repository.

## Organ

[Organ](https://github.com/d0lim/organ)은 개인용 PKM + 할 일 앱입니다. `0.0.1-alpha8`부터 Swift·AppKit으로 다시 만든 트리를 배포합니다 — 서버 없이 로컬 SQLite 저널 하나에 모든 기록이 Event로 남습니다. Apple Silicon, macOS 27 이상.

```bash
brew install --cask d0lim/tap/organ
```

alpha8에는 캡처 바 · Inbox 결정 큐 · Today(목록 · 타임라인 · 제자리 편집 · 2초 머무는 완료) · "노트 남기기"가 있고, 노트 에디터는 아직 없습니다. 이전 알파(Wails·Go, alpha1~7)와는 다른 앱이고 데이터는 이어지지 않습니다. 앱은 Developer ID로 서명하고 Apple 공증을 받았습니다. 압축 파일과 체크섬은 이 저장소의 `organ-v<버전>` 릴리스에 있고, `Casks/organ.rb`는 organ 저장소의 `scripts/package-mac.sh` 결과를 손으로 옮깁니다.

기존 설치는 `brew update` 후 `brew upgrade --cask d0lim/tap/organ`으로 갱신합니다.

## Garakuta

[Garakuta](https://github.com/d0lim/garakuta) is a menu bar organizer, notch
panel and window switcher for macOS 15 and later.

```bash
brew install --cask d0lim/tap/garakuta
```

`Casks/garakuta.rb` is written by `scripts/update-cask.sh` in the Garakuta
repository on each release.

## aaswap

[aaswap](https://github.com/d0lim/aaswap) — Agent Account Swap, which manages
several agent CLI logins on one machine.

```bash
brew install --cask d0lim/tap/aaswap
```

Linux needs Homebrew 4.5.0 or newer, which is where Linux cask support landed.

## Coming from ccswap

aaswap was renamed from ccswap. The `ccswap` cask is deprecated and points here;
it keeps installing the last ccswap release but will not get another one.

```bash
brew uninstall --cask ccswap
brew install --cask d0lim/tap/aaswap
aaswap account adopt        # takes over the ccswap store, once
```

`Casks/aaswap.rb` is generated by GoReleaser on each release. Do not edit it by
hand — the next release overwrites it.
